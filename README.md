# System Cleaner Pro

> A fast, modern Windows junk file cleaner. Made by AI.

System Cleaner Pro is a lightweight, modern Windows optimization tool built with Python and CustomTkinter. It scans and removes system junk files in real time to free up storage and boost performance.

## 🌟 Features
* **Real-time Junk Counter:** Instantly calculates the total number of temporary files on launch.
* **Targeted Cleaning:** Individual cleanup options for Temp, %Temp%, Prefetch, DirectX Shaders, Delivery Optimization, Thumbnails, and Recycle Bin.
* **One-Click Full Clean:** Automated process to wipe all junk locations in one go.
* **Chris Titus Tech Utility:** Quick-launch integration for the official Windows utility script.
* **Modern UI:** Supports Dark and Light themes, real-time progress bar, and ETA timer.
* **Automatic Elevation:** Auto-prompts for Administrator permissions required for deep system cleaning.

## 🛠️ Requirements
* **OS:** Windows 10 / 11
* **Python:** 3.8 or higher
